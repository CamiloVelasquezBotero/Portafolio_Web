Welcome to the repository of my **personal website**, designed with an interactive, modern, and high-performance approach. This space serves as a professional showcase of my background, key projects, technical skills, and industry certifications.

🔗 **Live Website:** [camilovelasquezbotero.vercel.app](https://camilovelasquezbotero.vercel.app/)

---

## ⚡ Key Features

*   📟 **Interactive Command Console:** An animated loading sequence simulating a terminal system initialization.
*   🎨 **Modern & Dynamic Design:** A fluid user interface optimized for all devices, utilizing subtle animations and micro-interactions.
*   🏆 **Credentials & Certifications:** An organized, dynamic module linking directly to official credentials and certificates.
*   📨 **Secure Contact Form:** A reliable messaging form integrated to facilitate quick and straightforward professional inquiries.
*   ⚡ **Optimized Performance:** Built with robust SEO practices and fast load times powered by Next.js.

---

## 🛠️ Tech Stack

| Component | Technology |
| :--- | :--- |
| **Core Framework** | [Next.js 14](https://nextjs.org/) (React 18) |
| **Styling & Layout** | [Tailwind CSS](https://tailwindcss.com/) & PostCSS |
| **Animations** | Vanilla CSS Animations & React Hooks |
| **Hosting & Deployment** | [Vercel](https://vercel.com/) |

## 🧬 Project Structure

```text
src/
├── app/                  # Main routing and Next.js layout configuration
└── components/           # Modular user interface components
    ├── About.jsx         # "About Me" section and technical background
    ├── BootLoader.jsx    # Simulated loading sequence on entry
    ├── Certificates.jsx # Dynamic certificate viewer with hover scanline effects
    ├── Contact.jsx      # Integrated secure contact form
    ├── CyberBackground.jsx # Interactive animated canvas background
    ├── Hero.jsx          # Welcome console window and call-to-action
    └── Header/Footer     # Navigation layout and footer credits
```
